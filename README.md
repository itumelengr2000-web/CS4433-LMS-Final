# CS4433 LMS Final Project

This repository contains the complete moderated Learning Management System project from Phase 1 through Phase 8. The final report is `CS4433_FINAL_REPORT.pdf`; the Word version is provided for editing.

## Phase folders

| Phase | Folder | Main evidence |
|---|---|---|
| 1 | `phase1-planning/` | Project planning and management |
| 2 | `phase2-requirements/` | Stakeholder analysis, SRS and use cases |
| 3 | `phase3-design/` | Architecture, UML, behavioural and database design |
| 4 | `phase4-implementation/`, `src/`, `include/`, `tests/` | C++17 implementation, build guide and automated tests |
| 5 | `phase5-verification/` | Test strategy, results and screenshot guide |
| 6 | `phase6-quality-assurance/` | QA evidence, static analysis and configuration management |
| 7 | `phase7-deployment/` | Installation, user manual, release notes and deployment diagram |
| 8 | `phase8-maintenance/` | CR-01 whole-class extension and regression evidence |

The report uses short clickable links to these repository artefacts instead of embedding large figures. Open the Markdown documents on GitHub for readable text and open the `figures/` folders for UML and evidence images.
